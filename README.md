# WJCT_theme
A skills test theme for WJCT


1. This theme is a child theme based on the WP core TwentyTwentyFive theme
2. It includes a custom single template for the custom post type Cat Picks

3. Installation
  - Login to WP admin and navigate to Appearance > Themes
  - Locate the TwentyTwentyFive Child theme and click Activate

4. Stylesheet will have minimal changes to the over all color / font aesthetic

5. Footer overwrite in the templates folder as parent themes footer text did not havve a footer text hook!

6. Future improvemnts - Id like to create a wider and more flxible patterns/template
